# 电量托盘

![BatteryTray](docs/BatteryTray.png)

一个干净、便携、开源的 Windows 电池百分比托盘显示程序。

## 特性

- 托盘图标实时显示电量数字，满电时显示 `FL`
- 悬停显示**当前功耗与预计剩余时间**，单击弹出面板看**循环次数、健康度、温度**等详情
- 图标按当前 DPI 现画，跟随系统深浅主题，面板与右键菜单一并换色
- **事件驱动刷新，不轮询，空闲时几乎不占 CPU**
- 可选电量日志，记录每格用时、充放电切换、睡眠掉电，只写在程序目录下
- 一键开机自启，只写 `HKCU`，**无需管理员权限**
- 完全便携：不写配置、不留注册表垃圾，删除 exe 即卸载
- 零第三方依赖，**单个 exe，无需任何运行时**

## 系统要求

- Windows 10 及以上，64 位

## 安装与使用

1. 从 [Releases](../../releases) 下载 `BatteryTray.zip` 并解压，得到一个 `BatteryTray` 文件夹
2. 把这个文件夹放到一个**有写入权限**的位置，例如 `D:\Software\`
3. 启动文件夹里的 `BatteryTray.exe`，托盘出现电量数字后即开始工作

## 技术细节

原生 C++23 + Win32 API，无第三方库、无框架。图标按 DPI 现画后转 `HICON`；功耗与时长直接读电池驱动，
不用 `GetSystemPowerStatus` 的整数百分比；刷新全靠系统推送的电源事件，没有定时器。

这些选择的理由、试过又放弃的方案，以及完整的功能与实现约束，都在
[docs/specification.md](docs/specification.md)。
